# book_manager

Roomline PMS — система управления бронированием отеля. Весь код — в `hotel-booking/`,
описание проекта и команды — в `CLAUDE.md`, живой журнал — в `hotel-booking/NOTES.md`.

## Локальные файлы, которых нет в git

Два файла машинно-специфичны (пароли и абсолютные пути), поэтому в репозитории
лежат только их образцы:

- `.mcp.json.example` → скопировать в `.mcp.json` и подставить настоящий пароль
  базы вместо `<пароль>` (сам `.mcp.json` в `.gitignore`).
- `.claude/launch.example.json` → скопировать в `.claude/launch.json` и поправить
  пути под свою машину (в образце — пути этой).
