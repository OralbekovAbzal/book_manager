# Проверка установщика на чистой Windows

Открыть `sandbox-test.wsb` (нужна включённая Windows Sandbox). Внутри на рабочем
столе лежит папка `dist` с установщиком. Сборка ничего не знает об этой машине —
ровно так будет у клиента.

Отмечать по ходу: ✅ прошло · ❌ не прошло (что именно на экране).

## 1. Установка
- [ ] Двойной клик по `Roomline PMS Setup 1.0.0.exe` — мастер открылся без предупреждений, кроме стандартного SmartScreen (подпись кода не куплена, это ожидаемо).
- [ ] Путь установки менять не надо, «Установить» → дошло до конца, ярлык на рабочем столе появился.

## 2. Первый запуск (режим хост)
- [ ] Программа открылась. Первым должно появиться окно **«Настройка системы»** (пароль сисадмина, режим хост/клиент, папки).
- [ ] Задать пароль сисадмина (≥ 8 символов), выбрать **хост**, папки оставить по умолчанию → «Сохранить».
- [ ] После сохранения: программа перезапустилась сама, встроенная база стартовала. Сколько секунд прошло до окна входа — записать.
- [ ] Появился **мастер первого запуска** (название объекта → главный администратор → сотрудники → проверка), а не экран входа с `admin / admin`.
- [ ] Пройти мастер до конца → вход выполнен автоматически.

## 3. Работа
- [ ] Настройки → Номера: завести категорию, корпус, 3 номера.
- [ ] Шахматка показывает эти номера. Завести бронь на завтра на 2 ночи.
- [ ] Тарифы → Цены: заполнить цену на неделю вперёд. Открыть бронь — итог посчитался.
- [ ] Касса → принять оплату по этой брони. В брони «Принято» обновилось.
- [ ] Снимки (иконка в шапке): список не пустой, есть авто-снимок.
- [ ] Настройки → Резервная копия → «Создать копию» → файл появился, размер разумный (сотни КБ, не мегабайты).

## 4. Живучесть
- [ ] Закрыть программу крестиком, открыть с ярлыка снова: брони на месте, вход по тому же паролю.
- [ ] Настройки → Резервная копия → восстановить из только что созданного файла → окно последствий показало, что терять нечего → восстановилось, бронь и платёж на месте.

## 4а. Живучесть хоста (волна 7)
- [ ] Шахматка → поиск «асель» строчными находит бронь «Асель …» (встроенная база с локалью C.UTF-8).
- [ ] Диспетчер задач → завершить `postgres.exe` (тот, что дочерний у «Roomline PMS») → через 5–10 с программа снова работает без перезапуска; в `host-debug.log` строки «база остановилась — пробую поднять заново» и «база поднята с попытки 1».
- [ ] Закрыть программу крестиком → в диспетчере не осталось ни «Roomline PMS.exe», ни `postgres.exe`; в `host-debug.log` есть `pg_ctl stop: ok`; в папке `pgdata` нет `postmaster.pid`.
- [ ] Удалить `config.json` (пароль базы!) → запуск → окно «Настройка системы» → хост, папки по умолчанию → программа открылась, брони и вход прежним паролем на месте (пароль взят из `pgdata\hotel-booking-secret.json`; в логе «пароль базы: sidecar»).
- [ ] Обновление поверх: перед первым запуском новой версии рядом с `pgdata` появилась папка `pgdata-before-update` (только если в сборке есть новые миграции).
- [ ] Мастер повторно не открывается (волна 8): после прохождения мастера открыть `http://<хост>:3001/api/setup/status` в браузере → `"needsSetup":false`; в `logs\combined.log` строка «мастер первого запуска пройден».
- [ ] Через 8 часов работы (или с `JWT_EXPIRES_IN` короче в dev) шахматка сама уходит на вход с полосой «Сессия истекла — войдите заново».

## 5. Что НЕ проверяется в песочнице (нужна полная виртуалка)
- Перезагрузка Windows (песочница её не поддерживает).
- Обновление с сервера обновлений (его ещё нет).
- Второй ноутбук в режиме «клиент» (нужна вторая машина в одной сети).

## Куда смотреть, если что-то не так
- Лог хоста: `%APPDATA%\hotel-booking-desktop\host-debug.log` (внутри песочницы —
  `C:\Users\WDAGUtilityAccount\AppData\Roaming\hotel-booking-desktop\`).
- Конфиг: там же `config.json`.
- Логи сервера: папка данных → `logs\error.log`, `logs\combined.log`.
Скопировать содержимое наружу можно только вручную (папка dist — только чтение):
открыть файл в Блокноте и прочитать, либо временно включить `ReadOnly=false` в `.wsb`.
