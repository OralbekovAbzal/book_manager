# electron/db

- **`seed.sql`** — начальные ДАННЫЕ свежей установки: главный администратор,
  категории номеров, стандартные метки броней. Только данные, схемы здесь нет.

Схема базы (таблицы, индексы, constraint'ы) живёт **только** в миграциях Prisma:
`server/prisma/migrations/`. Раньше рядом лежал написанный руками `init.sql` —
из него разворачивалась свежая установка, и каждая новая таблица требовала двух
правок (schema.prisma + init.sql), а обновить базу у клиента с данными было нечем.

Теперь оба сценария — одни и те же файлы:

- пустая база → `prisma migrate deploy` создаёт всё с нуля, затем `seed.sql`;
- база клиента с данными → тот же `migrate deploy` доводит её до текущей схемы.

Порядок при изменении схемы — в `NOTES.md`, раздел «Правила/грабли».
