## 2. Что в порядке

- **Вход/сессии** — `Login.tsx`: вход, ошибка «Внутренняя ошибка сервера» при CORS-отказе (см. D7-001), пояснение на экране входа после отзыва; `useAuthStore.logout` → `POST /auth/logout` → второе окно гаснет по сокету за секунду; все три учётки пережили восстановление копии (tokenVersion совпал).
- **Шахматка** — `GridRow.handleMouseDown`/`SelectionMenu`: прошлое блокирует «Заезд»/«Бронь» и оставляет «Ремонт»; сегодня — «Заезд»; будущее — «Бронь»; drag CONFIRMED → форма с новым номером и датами → `PUT`; drag CHECKED_IN → «Переезд гостя» с предпросмотром «что произойдёт»; серверные тексты 409/400 (пересечение с `conflict`, буфер с названием брони и метки, квота с партнёром и датами, нулевая ночь, прошлое) — точные и человеческие; граница буфера метки (`flagEffects`) соблюдена в `check-availability`.

- **Деньги (форма)** — `charges.js`/`calculator.ts` для наборов A, C+D, E, F совпадают до тенге: проживание по календарю, дни без цены пропускаются с предупреждением, завтрак на часть гостей, дети/доп. место (доп. место = «взрослый едок»), предоплата %, пересборка при смене дат.

## 5. Не проверено (бюджет)

- `@media print`, ориентация и разбиение на страницы, «Сохранить PDF» в Electron, одновременно открытые отчёт и счёт — инструмент не эмулирует печать; PDF-кнопка отчётов открыла системный диалог печати и заблокировала страницу на время.
- Enter в поле пароля формы входа — не воспроизвёлся инструментом (форма стандартная `<form onSubmit>`, вероятно ограничение эмуляции клавиш).
- Импорт JSON отчёта через кнопку («Импорт из JSON» = `<input type=file>`) — проверен только через `POST /reports/import`.
- Масштаб 125 %, реальные ноутбуки, тач — не проверялось; ширины только через эмуляцию viewport.
- Деактивация учётки и разрыв сокета по `isActive` — не выполнялась (не в 12 сценариях); смена пароля тестовых учёток — не выполнялась.
- Оптимизатор: ветка «план устарел → 409 при `apply`», квоты/буферы при перестановке — не воспроизводились.
- Переименование живого корпуса/особенности (переписывание номеров) — только тестовый корпус без номеров; «Восстановить из файла» номерного фонда — нет (нужен файл).
- Realtime для номеров/тарифов — не проверялось отдельно (по коду тот же класс, что категории); полоса денег в просмотре брони во втором окне при платеже из первого — не проверялась (закрыто D7-010 по «Кассе»).
- Контекстное меню CANCELLED/NO_SHOW под STAFF — не проверялось (только CHECKED_IN и CHECKED_OUT).
- Сценарий 3: «день без цены» проверен только с завтраком; скидка + услуги без ручной строки — не проверялись отдельно.
- Второе окно во время `next-day`/оптимизатора — проверено только по сетевым запросам сетки, не по экрану.

## 6. Вопросы владельцу

1. **STAFF-модель прав** (D7-012): роль сотрудника должна ли видеть адресную книгу гостей с телефонами, запускать «Выручку»/«Долги», делать снимки, считать оптимизатор, менять `paidAmount`? Клиент прячет, сервер разрешает — что из этого задумано?
2. **Сплит при переезде** (D7-013): как делить питание/услуги без даты — по ночам пропорционально или заново пересобирать обе части по тарифу?
3. **Ручная скидка + процентная** (D7-009): какая база правильная — «10 % от всего счёта, включая ручные скидки» (сервер) или «10 % от проживания и услуг, ручные строки отдельно» (одна из двух версий формы)? Пока форма показывает два разных числа, а сервер третье.
4. **«Удалить бронь»** (D7-007): оставить формулировку «удалить» при фактическом CANCELLED или переименовать в «Отменить» и показывать отменённые в кассе/долгах явно?
5. **Квота партнёра из формы** (D7-005): нужна ли возможность продать номер из квоты прямому гостю без релиза (диалог уже есть)?
6. **Журнал действий при восстановлении копии** (D7-015): должен ли `AuditLog` быть append-only (исключить из копии, как `Snapshot`), или откат журнала приемлем?
7. **«Очистить период» в тарифах** (D7-011): нужно ли подтверждение и/или снимок цен перед очисткой?
8. **Двойная отправка** (D7-014): блокировать кнопку синхронно при первом клике?
9. **Корпуса в верхнем регистре** (D7-017): это правило или побочный эффект нормализации при импорте?
10. **Бизнес-дата в календарях** (D7-008): открывать выбор даты на месяце смены, а не устройства?
